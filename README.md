# FastAPI E-Commerce API

RESTful API для управління каталогом товарів та категорій інтернет-магазину. Проєкт розроблено з використанням сучасного стеку FastAPI та SQLAlchemy 2.0 (Clean Architecture, Layered pattern) згідно з найкращими практиками розробки.

## 🛠 Технології
* **Фреймворк:** FastAPI (>=0.115)
* **База даних:** MySQL 8.0 (aiomysql)
* **ORM:** SQLAlchemy 2.0 (Async)
* **Міграції:** Alembic
* **Валідація:** Pydantic v2
* **Лінтер:** Ruff
* **Інфраструктура:** Docker & Docker Compose

## 🚀 Швидкий старт (Локальний запуск)

### 1. Клонування репозиторію

```bash
git clone <ваше_посилання_на_репозиторій>
cd fastapi-test-task
```

### 2. Налаштування середовища
Створіть файл змінних середовища на основі прикладу:
```bash
cp .env.example .env
```

### 3. Запуск інфраструктури (Docker Compose)
Підніміть контейнери з базою даних MySQL, phpMyAdmin та самим API:
```bash
docker compose up --build -d
```

### 4. Застосування міграцій бази даних
Створіть структуру таблиць за допомогою Alembic:
```bash
docker exec -it fastapi_api alembic upgrade head
```

### 5. Наповнення бази тестовими даними (Seeder)
Запустіть скрипт для генерації ієрархії категорій та товарів:
```bash
docker exec -it fastapi_api python seed.py
```

## 📖 Документація та Тестування API

Після успішного запуску, інтерактивна документація Swagger UI буде доступна за адресою:
👉 **[http://localhost:8000/docs](http://localhost:8000/docs)**

### Тестування через Postman
Для зручного ручного тестування складних запитів (наприклад, створення товару з вкладеними атрибутами та зображеннями), у корені репозиторію знаходиться файл `fastapi-test-task.postman_collection.json`.

**Як імпортувати:**
1. Відкрийте Postman.
2. Натисніть кнопку **Import** (у лівому верхньому куті).
3. Виберіть файл `fastapi-test-task.postman_collection.json` з папки проєкту.
4. Перейдіть до імпортованої колекції та використовуйте готові запити (змінна `base_url` вже налаштована на `http://localhost:8000`).

## 🗄 Управління базою даних
Ви можете переглядати базу даних через зручний веб-інтерфейс phpMyAdmin, який автоматично піднімається разом з проєктом:
* **URL:** http://localhost:8080
* **Логін:** `root`
* **Пароль:** `root_secret` (або значення з вашого `.env` файлу)

## 📁 Структура проєкту
```text
fastapi-test-task/
├── src/               # Вихідний код додатку
│   ├── api/v1/        # HTTP роутери (Endpoints)
│   ├── core/          # Глобальні налаштування (Pydantic Settings)
│   ├── db/            # Налаштування підключення до БД (Async Engine & Session)
│   ├── models/        # SQLAlchemy 2.0 ORM моделі
│   ├── schemas/       # Pydantic моделі для валідації вхідних/вихідних даних
│   ├── services/      # Бізнес-логіка (CRUD операції)
│   └── main.py        # Точка входу FastAPI
├── alembic/           # Файли міграцій бази даних
├── docker-compose.yml # Налаштування інфраструктури (API, БД, phpMyAdmin)
├── Dockerfile         # Інструкція для збірки образу FastAPI
├── requirements.txt   # Залежності проєкту (версії бібліотек)
├── seed.py            # Скрипт для наповнення БД тестовими даними
├── .env.example       # Приклад змінних середовища
└── alembic.ini        # Головна конфігурація Alembic
```
